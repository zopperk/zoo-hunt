ADMIN DASHBOARD VISUAL STYLE
The admin interface should use the same visual language, but prioritize information density and usability.
Do NOT make it look like a generic:
Stripe dashboard
Linear dashboard
Notion dashboard
Tailwind SaaS template
Instead, make it feel like:
GAME MASTER HQ
Use:
    •    Cream background
    •    Green navigation
    •    Illustrated section headers
    •    Paper cards
    •    Large score numbers
    •    Chunky controls
    •    Small animal illustrations as accents
The admin UI can be somewhat more utilitarian than the player app.

ANIMATIONS
Animations should be playful but restrained.
Examples:
    •    Points bounce upward when awarded
    •    Confetti on successful submission
    •    Cards gently slide into place
    •    Stamps appear when clues are completed
    •    Animal cards flip/reveal
    •    Score changes animate
    •    Locked clues wiggle subtly when unavailable
    •    Monkey mascot can wave/celebrate
Avoid modern flashy UI animations.
Everything should feel like physical printed game pieces coming to life.

RESPONSIVE BEHAVIOR
The PLAYER EXPERIENCE is primarily designed for an iPhone.
Design for approximately:
390 × 844 px
as the primary reference viewport.
It should feel like a native mobile game even though it is web-based.
The ADMIN EXPERIENCE should work especially well on:
    •    Desktop
    •    Laptop
    •    Tablet
The admin dashboard can use a wider multi-column layout.

MOST IMPORTANT DESIGN RULE
When making a design decision, ask:
"Would this look at home in the original mockups?"
If the answer is no, don't use it.
The supplied mockups should be treated as the source of truth for visual direction.
Prioritize visual consistency over conventional web-app design patterns.
The finished product should feel like someone took the illustrated mockup and turned every screen into a real, functional app, rather than someone designing a normal web app and adding some retro colors afterward.
